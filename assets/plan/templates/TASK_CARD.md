# Bounded task card template

This is a generation worksheet, not a dispatchable item. G5-02 creates tasks/<ITEM>.md with every field resolved.

TRACK: exact literal slug from ROUTES.md
ITEM: stable unique ID listed in TASKS.md
- Title and role: one outcome; builder or independent reviewer
- Subject and depth: exact subject ID and assigned purpose within mandatory D1-D5, or shared work
- Requires accepted: exact IDs, not phrases such as "previous phase"
- Required context: precise documents and source sections
- Preconditions: source access, decisions, tools and candidate baseline
- Owned paths or sections: exact writable destinations and shared coordination fields
- Exclusions: protected sources and work outside this outcome

## Steps

Write a short sequence of concrete actions. Begin with evidence and audience intent, then production and relevant verification. Avoid broad instructions such as "finish all remaining explanations."

## Deliverables

Name exact artifacts and candidate evidence. Each deliverable must be inspectable without replaying the chat.

## Acceptance

State source, instructional, medium and preservation criteria that discriminate a good result from an incorrect one. Include a normal and changed case where relevant. Name required render or behavior evidence and any explicitly optional audience test.

## Stop and handoff

Freeze the candidate, record observations and missing evidence, and hand off this same ITEM for fresh review. State repair ownership and the finite attempt limit. Update durable state before delivering the thin prompt in chat.
