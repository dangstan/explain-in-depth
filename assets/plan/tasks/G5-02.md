## Steps

1. Assign stable subject IDs and select a representative pilot. Bound the release before adding tasks.
2. Design all five mandatory depths for every subject. Complete each brief with distinct learning outcomes, a detailed-map specification and a coherent case.
3. Define exact audience destinations and source-access routes in the chosen medium. Inventory real compatibility requirements.
4. Specify teach-back, normal/changed-case and format acceptance. Distinguish expert judgment from actual participant evidence.
5. Generate all concrete production cards with exact ownership, dependencies and acceptance; include only requested companions. Bind pilot and final-review prerequisites to actual IDs.
6. Write run/PLAN.json using PLAN_SCHEMA.md, synchronized with TASKS.md, cards and output destinations. Run the skill validator, then validate unique IDs, file existence, TRACK consistency, acyclic dependencies, a reachable finite endpoint, coverage and exact card mappings for all five mandatory depths of every subject and absence of unresolved fields.
7. Freeze and hand off the blueprint for independent review before G5-03.
